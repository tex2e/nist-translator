Abstract

原本 PDF p.4

要旨

This report presents the ANSI/NIST-ITL 1-2025 requirements for exchanging biometric and forensic data using a machine-readable specification (MRS) that allows software tools to process the requirements directly. NIST developed a modular JSON architecture and an automated build process to manage, validate, and transform the MRS data using a proof-of-concept HTML specification directly from the JSON source. It demonstrates how the MRS can augment the base standard for developers, testers, and auditors to lower adoption barriers, reduce interpretation gaps, and provide a maintained digital companion to the ANSI/NIST-ITL 1-2025 specification.

原本 PDF p.4

この報告書は、ソフトウェアツールが要件を直接処理できる機械可読仕様（MRS）を用いて、バイオメトリクスデータおよび法科学データを交換するための ANSI/NIST-ITL 1-2025 の要件を示します。NIST は、モジュール式の JSON アーキテクチャと自動ビルドプロセスを開発し、MRS データを管理、検証、変換するとともに、JSON ソースから直接、概念実証用の HTML 仕様を生成しました。この報告書は、MRS が基本規格を開発者、試験者、監査者向けに補完し、導入障壁を下げ、解釈のずれを減らし、ANSI/NIST-ITL 1-2025 仕様を補う、継続的に保守されるデジタル資料を提供できることを示します。

1. Introduction

原本 PDF p.6

1. はじめに

1.1. Background

原本 PDF p.6

1.1. 背景

The first version of the ANSI/NBS-ICST 1-1986 standard was published by NIST (then the National Bureau of Standards) in 1986 as a 53-page document. That version focused exclusively on fingerprint identification and a data format for information exchange between organizations. Since then, the standard has evolved to meet the needs of national and international law enforcement and biometric organizations by incorporating new biometric modalities, encoding formats, and metadata fields.

原本 PDF p.6

ANSI/NBS-ICST 1-1986 規格の最初の版は、1986年に NIST（当時の米国標準局）により、53 ページの文書として刊行されました。その版は、指紋の識別と、組織間で情報を交換するためのデータ形式だけに焦点を当てていました。それ以来、この規格は、新しいバイオメトリクスのモダリティ、エンコーディング形式、メタデータフィールドを取り込みながら、国内外の法執行機関およびバイオメトリクス関連組織のニーズに応えるべく進化してきました。

ANSI/NIST-ITL 1-2025, Data Format for the Interchange of Fingerprint, Facial and Other Biometric Information [1], is the latest revision of the global standard for biometric and forensic data. It has expanded to include guidance and data format specifications for various biometric modalities, including facial, iris, plantar, and DNA data. As the number of modalities and the complexity of the information have increased over time, the specification has grown to exceed 600 pages. Traditionally, software developers and system integrators have used this standard as a text-based reference, manually extracting and interpreting technical requirements to develop conformant software.

原本 PDF p.6

ANSI/NIST-ITL 1-2025『Data Format for the Interchange of Fingerprint, Facial and Other Biometric Information』[1] は、バイオメトリクスデータおよび法科学データに関する国際規格の最新の改訂版です。この規格は、顔、虹彩、足底、DNA のデータなど、さまざまなバイオメトリクスのモダリティに関するガイダンスとデータ形式の仕様を含むよう拡張されてきました。モダリティの数と情報の複雑さが時間とともに増すにつれ、仕様は 600 ページを超えるまでに大きくなりました。従来、ソフトウェア開発者とシステムインテグレーターは、この規格をテキストベースの参考資料として用い、技術的要件を手作業で抽出・解釈して、適合したソフトウェアを開発してきました。

1.2. Problem Statement

原本 PDF p.6

1.2. 問題の所在

The ANSI/NIST-ITL 1 standards have historically required extensive cross-referencing within the document. Requirements for a single data element (e.g., data type, character constraints, occurrence limits) are often distributed and repeated across narrative sections and associated tables. This fragmentation has increased the risk of ambiguity when separate sections present inconsistent or conflicting guidance, particularly in a long and complex technical specification maintained over multiple revisions. Organizations have therefore had to reconcile related requirements before implementing them, and independent reconciliation efforts could lead to divergent interpretations and subtle interoperability challenges.

原本 PDF p.6

ANSI/NIST-ITL 1 規格は、歴史的に、文書内での広範な相互参照を必要としてきました。単一のデータ要素に対する要件（例：データ型、文字の制約、出現回数の上限）は、本文の各節と関連する表に分散し、重複して記載されていることが多くあります。この断片化により、複数の節が一貫しない、あるいは矛盾するガイダンスを示す場合、とりわけ、複数回の改訂を経て維持されてきた長く複雑な技術仕様では、曖昧さが生じるリスクが高まりました。そのため、各組織は、関連する要件を実装する前に整合させなければならず、それぞれが独自に整合させる取り組みは、解釈の食い違いや、微妙な相互運用性の課題につながるおそれがありました。

NIST developed the Biometric Conformance Test Software (BioCTS) to validate whether implementations conform to the standard. BioCTS is valuable, but it is primarily a reactive tool — it identifies nonconformance after implementation work has begun. It does not negate the need to interpret requirements before design and development, nor does it prevent misunderstandings from being built into an implementation.

原本 PDF p.6

NIST は、実装が規格に適合しているかどうかを検証するために、Biometric Conformance Test Software（BioCTS）を開発しました。BioCTS は有用ですが、主として事後対応型のツールであり、実装作業が始まった後で不適合を識別します。設計や開発の前に要件を解釈する必要がなくなるわけではなく、誤解が実装に組み込まれることを防ぐものでもありません。

Before this NIST-led effort, an external initiative created “Machine-Readable Tables” for the 2011 and 2013 revisions. Those spreadsheet-based tables used proprietary software to generate XML representations of the standard’s requirements. The resources were not maintained and had limited industry adoption, so most organizations have continued to extract requirements independently from the narrative text.

原本 PDF p.6

この NIST 主導の取り組みの前に、外部のイニシアチブが 2011 年版および 2013 年版向けに「機械可読テーブル（Machine-Readable Tables）」を作成していました。これらのスプレッドシートベースのテーブルは、独自のソフトウェアを使って規格の要件の XML 表現を生成するものでした。これらのリソースは保守されず、業界での採用も限られていたため、ほとんどの組織は引き続き、本文の記述から要件を独自に抽出しています。

1.3. Purpose and Scope

原本 PDF p.7

1.3. 目的と範囲

This report describes NIST’s development of a machine-readable specification (MRS) for ANSI/NIST-ITL 1-2025. The MRS represents requirements from the text standard as structured JSON data. JSON was selected because it can represent the standard’s hierarchy (e.g., transactions, records, fields, subfields, information items) in a form that software can validate, transform, and use directly. The MRS is intended to supplement the human-readable standard.

原本 PDF p.7

本報告書は、ANSI/NIST-ITL 1-2025 の機械可読仕様（MRS）に関する NIST の開発について説明します。MRS は、テキスト形式の規格に含まれる要件を、構造化された JSON データとして表現します。JSON を選んだのは、規格の階層（例: トランザクション、レコード、フィールド、サブフィールド、情報項目）を、ソフトウェアが検証、変換し、直接利用できる形で表現できるためです。MRS は、人間が読める規格を補完することを意図しています。

The scope of this report covers the process used for extracting requirements for transactions, records, fields, subfields, and information items and codifying them into a structured JSON format. This document also provides a technical overview of the supporting infrastructure, including the strongly typed JSON schema and the suite of Python scripts developed to aggregate, validate, and transform the MRS data. Furthermore, the report describes the workflow batch script used to ensure consistent, repeatable validation and the generation of a proof-of-concept HTML output page. This generated output demonstrates that the machine-readable data can accurately recreate human-readable requirements while remaining accessible to automated tools. Finally, this report outlines the strategy for releasing the project as an open-source resource. It describes how making the entirety of the effort publicly available is intended to foster a collaborative environment in which the biometric community can provide feedback, submit fixes, and contribute to the maintenance of the MRS.

原本 PDF p.7

本報告書の範囲は、トランザクション、レコード、フィールド、サブフィールド、情報項目の要件を抽出し、それらを構造化された JSON 形式に体系化するために用いたプロセスです。本文書はまた、強く型付けされた JSON スキーマや、MRS データを集約、検証、変換するために開発した一連の Python スクリプトなど、それを支える基盤の技術的な概要も示します。さらに、ワークフローのバッチスクリプトを用いて一貫性と再現性のある検証を行う方法、および概念実証として HTML 出力ページを生成する方法について説明します。この生成された出力は、機械可読データが自動化ツールで利用可能な状態を保ちながら、人間が読める要件を正確に再現できることを示します。最後に、本報告書は本プロジェクトをオープンソースのリソースとして公開する戦略を概説します。取り組み全体を公開することで、バイオメトリクスコミュニティがフィードバックを寄せ、修正を提出し、MRS の保守に貢献できる協調的な環境を促進することを意図している点を説明します。

1.4. Significance and Global Impact

原本 PDF p.7

1.4. 意義と世界的な影響

Organizations worldwide rely on the ANSI/NIST-ITL 1 standard, including the International Criminal Police Organization (INTERPOL), the Federal Bureau of Investigation (FBI), and the Department of Homeland Security (DHS). The 2025 revision reduced the cross-reference burden for readers by placing related data specifications closer to the narrative requirements that describe them rather than distributing those details across many sections. It also resolved inconsistencies between the requirements represented in different sections of the text (e.g., within text clauses, tables, and figures).

原本 PDF p.7

The MRS for ANSI/NIST-ITL 1-2025 translates text-based biometric data exchange requirements into structured JSON.
