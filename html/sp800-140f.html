Abstract

原本 PDF p.4

概要

NIST Special Publication (SP) 800-140F replaces the approved non-invasive attack mitigation test metric requirements of ISO/IEC 19790 Annex F. As a validation authority, the Cryptographic Module Validation Program (CMVP) may supersede this Annex in its entirety. This document supersedes ISO/IEC 19790 Annex F and ISO/IEC 24759 paragraph 6.18.

原本 PDF p.4

NIST特別刊行物（SP）800-140Fは、ISO/IEC 19790附属書Fの承認済み非侵襲的攻撃緩和試験指標の要件を置き換える。検証機関として、暗号モジュール検証プログラム（CMVP）は、この附属書全体を置き換えることができる。本書は、ISO/IEC 19790附属書FおよびISO/IEC 24759の6.18項を置き換える。

1 Scope

原本 PDF p.6

1 適用範囲

This document specifies the Cryptographic Module Validation Program (CMVP) modifications of the methods to be used by a Cryptographic and Security Testing Laboratory (CSTL) to demonstrate conformance. This document also specifies the modification of methods for evidence that a vendor or testing laboratory provides to demonstrate conformity. Unless otherwise specified in this document, the test requirements are specified in ISO/IEC 24759 paragraph 6.18.

原本 PDF p.6

本書は、暗号モジュール検証プログラム（CMVP）が定める、暗号・セキュリティ試験機関（CSTL）が適合性を実証するために用いる方法の変更を規定する。また、ベンダーまたは試験機関が適合性を実証するために提出する証拠に関する方法の変更も規定する。本書で別途指定されない限り、試験要件はISO/IEC 24759の6.18項に規定される。

5.2 Modifications

原本 PDF p.7

5.2 変更

Modifications will follow a similar format as in ISO/IEC 24759. For additions to test requirements, new Test Evidence (TEs) or Vendor Evidence (VEs) will be listed by increasing the “sequence_number.” Modifications can include a combination of additions using underline and deletions using strikethrough. If no changes are required, the paragraph will indicate “No change.”

原本 PDF p.7

変更は、ISO/IEC 24759と同様の形式に従う。試験要件への追加については、新しい試験証拠（TE）またはベンダー証拠（VE）を、「sequence_number」を増やすことによって列挙する。変更には、下線による追加と取消線による削除の組み合わせを含めることができる。変更が不要な場合、その段落には「変更なし」と記載する。
