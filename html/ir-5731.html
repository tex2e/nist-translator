The Validated Products List (VPL) identifies information technology products that have been tested for conformance to Federal Information Processing Standards (FIPS) in accordance with Computer Systems Laboratory (CSL) conformance testing procedures, and have a current validation certificate or registered test report. The VPL also contains information about the organizations, test methods and procedures that support the validation programs for the FIPS identified in this document. The VPL includes computer language processors for programming languages COBOL, Fortran, Ada, Pascal, C, M[UMPS], and database language SQL; computer graphic implementations for GKS, CGM, PHIGS, and Raster Graphics; operating system implementations for POSIX; Open Systems Interconnection implementations; computer security implementations for DES, MAC and Key Management, product data implementations for IGES, and Open System Interconnection (OSI) implementations. The testing of products to assure conformance to the FIPS may be required by Government agencies in accordance with the FIPS, Federal Information Resources management Regulation (FIRMR) Parts 201.13 and 201.39, and the associated Federal ADP and Telecommunications Standards Index. The VPL is updated and published quarterly.

検証済み製品リスト（VPL: Validated Products List）は、コンピューターシステム研究所（CSL）の適合性試験手順に従って連邦情報処理標準（FIPS）への適合性が試験され、現行の検証証明書または登録済み試験報告書を持つ情報技術製品を示すものです。VPL には、本書で示す FIPS の検証プログラムを支える組織、試験方法および手順に関する情報も含まれています。VPL には、プログラミング言語 COBOL、Fortran、Ada、Pascal、C、M[UMPS] およびデータベース言語 SQL のコンピューター言語処理系、GKS、CGM、PHIGS およびラスターグラフィックスの実装、POSIX のオペレーティングシステム実装、Open Systems Interconnection の実装、DES、MAC および鍵管理のコンピューターセキュリティ実装、IGES の製品データ実装、ならびに Open System Interconnection（OSI）の実装が含まれます。FIPS、連邦情報資源管理規則（FIRMR）第201.13部および第201.39部、ならびに関連する Federal ADP and Telecommunications Standards Index に従い、政府機関は、FIPSへの適合を保証するため製品試験を要求される場合があります。VPL は四半期ごとに更新・発行されます。

5.1 FIPS POSIX Standard

5.1 FIPS POSIX 標準

The National Institute of Standards and Technology through its Computer Systems Laboratory (NIST/CSL) has established a conformance testing program for the Federal Information Standard for POSIX (FIPS 151-1 and FIPS 151-2). FIPS 151-2 replaced FIPS 151-1 in its entirely on October 15, 1993. These standards are based on the IEEE POSIX Std. 1003.1-1988 (FIPS 151-1) and ISO/IEC 9945-1:1990 (FIPS 151-2). The testing model includes a Certification Authority, NVLAP Accredited Testing Laboratories, Clients and the official NIST POSIX Conformance Test Suites. The Certification Authority is the Director of NIST/CSL. The National Voluntary Laboratory Accreditation Program (NVLAP), part of NIST, accredits the testing laboratories. The test suites NIST-PCTS:151-1 and NIST-PCTS:151-2 were developed by NIST/CSL and are based on the test assertions specified by the IEEE Standard for Information Technology — Test Methods for Measuring Conformance to POSIX, IEEE Std. 1003.3-1991 (NIST-PCTS:151-1) and the IEEE Standard for Information Technology — Test Methods for Measuring conformance to POSIX.1, IEEE Std 2003.1-1992 (NIST-PCTS:151-2).

6.2 Data Encryption Validation Tests

原本 PDF p.87

6.2 データ暗号化検証試験

FIPS PUB 46-2 specifies a cryptographic algorithm that converts plaintext to ciphertext using a 56-bit key. Testing procedures for the validation of devices as conforming to FIPS PUB 46-2 are described in the NBS Special Publication 500-20, Validating the Correctness of Hardware Implementations of the NBS Data Encryption Standard. The validation of a device is performed by running the Monte Carlo test described in the publication. The Monte-Carlo test consists of eight million encryptions and four million decryptions, with two encryptions and one decryption making up a single test. The test is designed to use the Electronic Codebook Mode (ECB) of DES. Although the actual test described in NBS Special Publication 500-20 is the same test used to validate devices today, the procedures for administering the test have changed. Currently, the test is performed by the vendor using initial values supplied by NIST. The vendor uses the supplied information to run the Monte-Carlo test and sends the results to NIST.

原本 PDF p.87

FIPS PUB 46-2 は、56 ビットの鍵を用いて平文を暗号文に変換する暗号アルゴリズムを規定しています。デバイスが FIPS PUB 46-2 に適合していることを検証するための試験手順は、NBS Special Publication 500-20 Validating the Correctness of Hardware Implementations of the NBS Data Encryption Standard に記載されています。デバイスの検証は、この刊行物に記載されたモンテカルロ試験を実行して行います。モンテカルロ試験は、800 万回の暗号化と 400 万回の復号で構成され、2 回の暗号化と 1 回の復号で 1 つの試験を構成します。この試験は、DES の Electronic Codebook Mode（ECB）を使用するように設計されています。NBS Special Publication 500-20 に記載された実際の試験は、現在デバイスの検証に使われている試験と同じですが、試験を実施する手順は変更されています。現在、試験はベンダーが NIST から提供された初期値を用いて行います。ベンダーは、提供された情報を用いてモンテカルロ試験を実行し、その結果を NIST に送付します。

6.3 Message Authentication Code (MAC) Validation System

原本 PDF p.87

6.3 メッセージ認証コード（MAC）検証システム

FIPS PUB 113, Computer Data Authentication, specifies a Data Encryption Algorithm which may be used to detect unauthorized intentional and accidental modifications to data. This process is known as data authentication. The algorithm is based on DES and is used to authenticate an entire binary message. FIPS PUB 113 is compatible with ANSI X9.9 which provides methods for authenticating an entire binary message as well as all or parts of a message which are in a coded character format. Procedures for the validation of products which implement FIPS PUB 113 and ANSI X9.9 are described in NBS Special Publication 500-156, Message Authentication Code (MAC) Validation System: Requirements and Procedures.

原本 PDF p.87

FIPS PUB 113 Computer Data Authentication は、データに対する意図的または偶発的な不正変更を検出するために使用できる Data Encryption Algorithm を規定しています。この処理は、データ認証と呼ばれます。このアルゴリズムは DES に基づいており、バイナリメッセージ全体の認証に使用されます。FIPS PUB 113 は ANSI X9.9 と互換性があり、ANSI X9.9 は、バイナリメッセージ全体の認証に加えて、符号化された文字形式のメッセージの全体または一部を認証する方法も提供します。FIPS PUB 113 と ANSI X9.9 を実装する製品の検証手順は、NBS Special Publication 500-156 Message Authentication Code (MAC) Validation System: Requirements and Procedures に記載されています。

6.4 Key Management Validation System (KMVS)

原本 PDF p.87

6.4 鍵管理検証システム（KMVS）

FIPS PUB 171 adopts ANSI X9.17 for Federal Government use. ANSI X9.17, Financial Institution Key Management (Wholesale), provides procedures and protocols for the secure generation, distribution, storage, entry, use and destruction of symmetric cryptographic keying material (e.g., DES). It provides key management solutions for a variety of operational environments, and as such, ANSI X9.17 contains a number of options. FIPS PUB 171 specifies a particular set of options whenever keying material is distributed using the protocols of ANSI X9.17. Procedures for the validation of products which conform to a subset of the options selected in FIPS PUB 171 are described in the Key Management Validation System: Point-to-Point Validation System document which is available from the Manager of the Security Group (see Section 6.5).

原本 PDF p.87

FIPS PUB 171 は、連邦政府で使用するために ANSI X9.17 を採用しています。ANSI X9.17 Financial Institution Key Management (Wholesale) は、共通鍵暗号の鍵素材（例: DES）の安全な生成、配布、保管、入力、使用および破棄のための手順とプロトコルを提供します。ANSI X9.17 はさまざまな運用環境に対する鍵管理の解決策を提供するため、多くのオプションを含んでいます。FIPS PUB 171 は、ANSI X9.17 のプロトコルを用いて鍵素材を配布する場合の特定のオプションの組を規定しています。FIPS PUB 171 で選択されたオプションの一部に適合する製品の検証手順は、Key Management Validation System: Point-to-Point Validation System 文書に記載されており、この文書は Manager of the Security Group（第 6.5 節を参照）から入手できます。
