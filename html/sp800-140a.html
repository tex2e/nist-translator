Abstract

原本 PDF p.4

要約

NIST Special Publication (SP) 800-140A modifies the vendor documentation requirements of ISO/IEC 19790 Annex A. As a validation authority, the Cryptographic Module Validation Program (CMVP) may modify, add, or delete Vendor Evidence (VE) and/or Test Evidence (TE) as specified under paragraph 5.2 of the ISO/IEC 19790. This document should be used in conjunction with ISO/IEC 19790 Annex A and ISO/IEC 24759 paragraph 6.13 as it modifies only those requirements identified in this document.

原本 PDF p.4

NIST特別刊行物（SP）800-140Aは、ISO/IEC 19790附属書Aのベンダー文書要件を変更する。検証機関として、暗号モジュール検証プログラム（CMVP）は、ISO/IEC 19790の5.2項に規定されているとおり、ベンダー証拠（VE）および／または試験証拠（TE）を変更、追加または削除できる。本書は、本書で特定した要件のみを変更するものであるため、ISO/IEC 19790附属書AおよびISO/IEC 24759の6.13項と併せて使用すべきである。

1 Scope

原本 PDF p.6

1 適用範囲

Federal Information Processing Standard (FIPS) 140-3 documentation requirements are specified in ISO/IEC 19790. This document specifies any additional requirements specified by the Cryptographic Module Validation Program (CMVP) for evidence that vendors provide to a Cryptographic and Security Testing Laboratory (CSTL) to demonstrate conformity. Unless otherwise modified in this document, the test requirements are specified in ISO/IEC 24759.

原本 PDF p.6

連邦情報処理標準（FIPS）140-3の文書化要件はISO/IEC 19790に規定されている。本書は、適合性を実証するためにベンダーが暗号・セキュリティ試験機関（CSTL）へ提出する証拠について、暗号モジュール検証プログラム（CMVP）が定める追加要件を規定する。本書で別途変更されない限り、試験要件はISO/IEC 24759に規定される。

5.2 Modifications

原本 PDF p.7

5.2 変更

Modifications will follow a similar format as in ISO/IEC 24759. For additions to vendor-supplied documentation, requirements will be listed by increasing the “sequence_number.” Modifications can include a combination of additions using underline and deletions using strikethrough. If no changes are required, the paragraph will indicate “No change.”

原本 PDF p.7

変更はISO/IEC 24759と同様の形式に従う。ベンダー提供文書への追加については、「sequence_number」を増加させて要件を列挙する。変更には、下線による追加と取り消し線による削除の組み合わせが含まれ得る。変更が不要な場合は、該当段落に「変更なし」と示す。
