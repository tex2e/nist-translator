[要約] SP 800-38A Addendum は、SP 800-38AのCBCモードに対し、暗号文盗用を用いる3つの変形CBC-CS1、CBC-CS2、CBC-CS3を規定する補遺です。ビット長がブロックサイズ以上であれば、ブロックサイズの倍数でなくても任意の平文入力を受け入れ、第2節から第4節で各変形の仕様を定めます。SP 800-38A で説明されているパディング方式と異なり暗号文が拡張されず、3つの変形の違いは暗号文ビットの順序だけです。

1 Introduction

原本 PDF p.7

1 はじめに

A limitation to Cipher Block Chaining (CBC) mode, as specified in NIST SP 800-38A, Ref. [1], is that the plaintext input must consist of a sequence of blocks. (In the rest of this publication, a block is called a “complete block” to emphasize the contrast with a “partial block” whose bit length is smaller than the block size.) Although Appendix A of Ref. [1] describes how padding methods can be used to meet this requirement, in such cases, the length of the resulting ciphertext expands over the length of the unpadded plaintext by the number of padding bits.

原本 PDF p.7

NIST SP 800-38A（参考文献[1]）に規定されているCipher Block Chaining（CBC）モードの制約の一つは、平文入力がブロックの列から成らなければならないことである。（本書の以降の部分では、ブロックサイズより小さいビット長を持つ「部分ブロック」との対比を明確にするため、ブロックを「完全ブロック」と呼ぶ。）参考文献[1]の付録Aでは、この要件を満たすためにパディング方式を使用できることを説明しているが、そのような場合、結果として得られる暗号文は、パディングされていない平文よりパディングのビット数だけ長くなる。

This addendum to Ref. [1] specifies three variants of CBC mode that accept any plaintext input whose bit length is greater than or equal to the block size, whether or not the length is a multiple of the block size. Unlike the padding methods discussed in Ref. [1], these variants avoid ciphertext expansion.

原本 PDF p.7

参考文献[1]への本補遺は、ビット長がブロックサイズ以上であれば、長さがブロックサイズの倍数であるかどうかを問わず、任意の平文入力を受け入れるCBCモードの3種類の変形を規定する。参考文献[1]で説明されているパディング方式とは異なり、これらの変形では暗号文が拡張されない。

These variants are denoted CBC-CS1, CBC-CS2, and CBC-CS3, where “CS” indicates “ciphertext stealing,” because when padding bits are needed in these variants, they are taken from the penultimate ciphertext block. The variants differ only in the ordering of the ciphertext bits. CBC-CS1 was specified as a suggestion on the NIST Computer Security Resource Center web site. CBC-CS2 is specified, for example, in Ref. [3]. CBC-CS3 is the variant specified for Kerberos 5 in Ref. [2].

原本 PDF p.7

これらの変形はCBC-CS1、CBC-CS2、CBC-CS3と表記する。「CS」は「ciphertext stealing（暗号文盗用）」を示す。これは、これらの変形でパディングビットが必要な場合、最後から2番目の暗号文ブロックからそのビットを取るためである。各変形の違いは、暗号文ビットの順序だけである。CBC-CS1は、NIST Computer Security Resource CenterのWebサイトで提案として規定された。CBC-CS2は、たとえば参考文献[3]で規定されている。CBC-CS3は、参考文献[2]でKerberos 5用に規定された変形である。

Below are the specifications for encryption and decryption using CBC-CS1, CBC-CS2, and CBC-CS3, building on the specification of the CBC encryption and decryption in Ref. [1]. Diagrams are given for CBC-CS1 encryption and decryption. Each variant inherits the relevant requirements of Ref. [1], e.g., on the underlying block cipher, the key, and the initialization vector.

原本 PDF p.7

以下に、参考文献[1]におけるCBC暗号化および復号の仕様を基礎として、CBC-CS1、CBC-CS2、CBC-CS3を用いた暗号化と復号の仕様を示す。CBC-CS1の暗号化と復号については図を示す。各変形には、基礎となるブロック暗号、鍵、初期化ベクトルなど、参考文献[1]の関連要件が適用される。

The following notational conventions apply to the specifications below:

原本 PDF p.7

以下の仕様には、次の表記規則を適用する。

•Bit strings are denoted with upper case letters; integers with lower case letters.

原本 PDF p.7

•ビット列は大文字で、整数は小文字で表す。

• The block size of the underlying block cipher is denoted \(b\).

原本 PDF p.7

• 基礎となるブロック暗号のブロックサイズを \(b\) と表す。

• For a bit string \(X\), the bit length of \(X\) is denoted \(\operatorname{len}(X)\).

原本 PDF p.7

• ビット列 \(X\) について、\(X\) のビット長を \(\operatorname{len}(X)\) と表す。

• For a bit string \(X\) and a positive integer \(r\) that does not exceed \(\operatorname{len}(X)\), the string consisting of the leftmost \(r\) bits of \(X\) is denoted \(\mathrm{MSB}_r(X)\), and the string consisting of the rightmost \(r\) bits of \(X\) is denoted \(\mathrm{LSB}_r(X)\).

原本 PDF p.7

• ビット列 \(X\) と、\(r\) が \(\operatorname{len}(X)\) を超えない正の整数であるとき、左端の \(r\) ビット（\(X\) のもの）から成る列を \(\mathrm{MSB}_r(X)\) と表し、右端の \(r\) ビット（\(X\) のもの）から成る列を \(\mathrm{LSB}_r(X)\) と表す。

• For an input block \(B\) and key \(K\), the output block of the cipher function (“encryption”) is denoted \(\mathrm{CIPH}_K(B)\), and the output block of the inverse cipher function (“decryption”) is denoted \(\mathrm{CIPH}^{-1}_K(B)\).

原本 PDF p.7

• 入力ブロック \(B\) と鍵 \(K\) に対し、暗号関数（「暗号化」）の出力ブロックを \(\mathrm{CIPH}_K(B)\) と表し、逆暗号関数（「復号」）の出力ブロックを \(\mathrm{CIPH}^{-1}_K(B)\) と表す。

In principle, the input strings to encryption and decryption for each of the variants may be any string whose length is not less than b bits, but typically an implementation is designed to accept a restricted set of lengths. For example, the set of lengths may be restricted to multiples of 8, so that the input strings may be represented with bytes/octets. The input lengths that an implementation allows are called the valid lengths.

原本 PDF p.7

原理上、各変形における暗号化および復号への入力文字列は、長さが b ビット以上であれば任意の文字列でよいが、通常、実装は限られた長さの集合を受け入れるよう設計される。たとえば、許容する長さを8の倍数に制限することがあり、これにより入力文字列をバイト／オクテットで表現できる。実装が許容する入力長を有効長と呼ぶ。

2 CBC-CS1の仕様

Algorithm: CBC-CS1-Encrypt

原本 PDF p.8

アルゴリズム：CBC-CS1-Encrypt

Input: plaintext \(P\), such that \(\operatorname{len}(P)\) is valid;
initialization vector \(\mathit{IV}\);
key \(K\).

原本 PDF p.8

入力：平文 \(P\)（ただし \(\operatorname{len}(P)\) が有効な長さであるもの）；
初期化ベクトル \(\mathit{IV}\)；
鍵 \(K\)。

Output: ciphertext \(C\), such that \(\operatorname{len}(C)=\operatorname{len}(P)\).

原本 PDF p.8

出力：暗号文 \(C\)（ただし \(\operatorname{len}(C)=\operatorname{len}(P)\) を満たすもの）。

Steps:

原本 PDF p.8

手順：

1. Let \(n\) be the smallest integer such that \(n\cdot b\ge \operatorname{len}(P)\), let \(d=\operatorname{len}(P)-(n-1)\cdot b\), and let \(P_1, P_2, \ldots, P_{n-1}, P_n^{*}\) be the unique sequence of bit strings such that:
a) \(P=P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\); and
b) \(P_1, P_2, \ldots\) and \(P_{n-1}\) are complete blocks.
Consequently, \(\operatorname{len}(P_n^{*})=d\), and \(1\le d\le b\), so that \(P_n^{*}\) is either a complete block or a nonempty partial block.

原本 PDF p.8

1. \(n\) を \(n\cdot b\ge \operatorname{len}(P)\) を満たす最小の整数とし、\(d=\operatorname{len}(P)-(n-1)\cdot b\) とする。また、\(P_1, P_2, \ldots, P_{n-1}, P_n^{*}\) を、次を満たすビット列の一意な列とする。
a) \(P=P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\)。かつ
b) \(P_1, P_2, \ldots\) および \(P_{n-1}\) は完全ブロックである。
したがって、\(\operatorname{len}(P_n^{*})=d\) であり、\(1\le d\le b\) となるため、\(P_n^{*}\) は完全ブロックまたは空でない部分ブロックのいずれかである。

2. Let \(\mathit{PAD}\) be the bit string consisting of \(b-d\) ‘0’ bits, and let \(P_n=P_n^{*}\parallel\mathit{PAD}\). Note that if \(P_n^{*}\) is a complete block, then \(\mathit{PAD}\) is the empty string, and \(P_n=P_n^{*}\).

原本 PDF p.8

2. \(\mathit{PAD}\) を \(b-d\) 個の ‘0’ ビットから成るビット列とし、\(P_n=P_n^{*}\parallel\mathit{PAD}\) とする。\(P_n^{*}\) が完全ブロックである場合、\(\mathit{PAD}\) は空の列となり、\(P_n=P_n^{*}\) であることに注意する。

3. Apply CBC encryption to the plaintext \((P_1, P_2, \ldots P_{n-1}, P_n)\) with initialization vector \(\mathit{IV}\) and key \(K\) to produce \((C_1, C_2, \ldots C_{n-1}, C_n)\).

原本 PDF p.8

3. 平文 \((P_1, P_2, \ldots P_{n-1}, P_n)\) に、初期化ベクトル \(\mathit{IV}\) と鍵 \(K\) を用いてCBC暗号化を適用し、\((C_1, C_2, \ldots C_{n-1}, C_n)\) を生成する。

4. Let \(C_{n-1}^{*}=\mathrm{MSB}_d(C_{n-1})\).

原本 PDF p.8

4. \(C_{n-1}^{*}=\mathrm{MSB}_d(C_{n-1})\) とする。

5. Return \(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\).

原本 PDF p.8

5. \(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\) を返す。

When \(P_n^{*}\) is a complete block, CBC-CS1-Encrypt is equivalent to CBC encryption.

原本 PDF p.8

\(P_n^{*}\) が完全ブロックの場合、CBC-CS1-Encrypt はCBC暗号化と等価である。

Diagram: Figure 1 below illustrates the CBC-CS1-Encrypt algorithm for the case that \(P_n^{*}\) is a partial block, i.e., \(d<b\). The bolded rectangles contain the inputs and outputs. The dotted rectangles provide alternate representations of two blocks in order to illustrate the role of the “stolen” ciphertext.

原本 PDF p.8

図：下の図1は、\(P_n^{*}\) が部分ブロック、すなわち \(d<b\) の場合のCBC-CS1-Encryptアルゴリズムを示す。太線の長方形は入力と出力を含む。点線の長方形は、「盗用」される暗号文の役割を示すために、2つのブロックの別の表現を示す。

In particular, the string of the \(b-d\) rightmost bits of \(C_{n-1}\), denoted \(C_{n-1}^{**}\), becomes the padding for the input block to the final invocation of the block cipher within the execution of CBC mode. The ciphertext that is returned in Step 5 above omits \(C_{n-1}^{**}\), because it can be recovered from \(C_n\) during decryption.

原本 PDF p.8

具体的には、右端 \(b-d\) ビットからなる \(C_{n-1}\) の部分文字列を \(C_{n-1}^{**}\) と表す。この文字列は、CBCモードの実行におけるブロック暗号の最後の呼び出しに対する入力ブロックのパディングとなる。上記ステップ5で返される暗号文では \(C_{n-1}^{**}\) を省略する。復号時に \(C_n\) から復元できるためである。

図表

図1：CBC-CS1-Encrypt。列ごとの CBC 暗号化である。P_1 は IV と排他的論理和（⊕）をとられ、CIPH_K を経て C_1 となる。C_1 は P_2 との排他的論理和に入り、それが CIPH_K を経て C_2 となる。省略されたブロックは省略記号と点線で示され、P_(n-1) と C_(n-1) まで続く。最後の列では、部分ブロック P_n* の後にゼロ「00...」（点線の箱）が続いて P_n となり、C_(n-1) と排他的論理和をとられて CIPH_K を経て C_n となる。下では C_(n-1) が C_(n-1)* と C_(n-1)**（点線の箱）に分けられ、波括弧で C_(n-1)* が出力（太枠）として選ばれる。破線の矢印が C_(n-1)** を最後の排他的論理和の右へ運び、そこで点線の箱 P_n* ⊕ C_(n-1)* と C_(n-1)** がその排他的論理和に入る様子が示されている。太枠の長方形は入力 IV、P_1、P_2、P_(n-1)、P_n* と出力 C_1、C_2、C_n、C_(n-1)* を表す。

Algorithm: CBC-CS1-Decrypt

原本 PDF p.9

アルゴリズム：CBC-CS1-Decrypt

Input: ciphertext \(C\), such that \(\operatorname{len}(C)\) is valid;
initialization vector \(\mathit{IV}\);
key \(K\).

原本 PDF p.9

入力：暗号文 \(C\)（ただし \(\operatorname{len}(C)\) が有効な長さであるもの）；
初期化ベクトル \(\mathit{IV}\)；
鍵 \(K\)。

Output: plaintext \(P\), such that \(\operatorname{len}(P)=\operatorname{len}(C)\).

原本 PDF p.9

出力：平文 \(P\)（ただし \(\operatorname{len}(P)=\operatorname{len}(C)\) を満たすもの）。

Steps:

原本 PDF p.9

手順：

1. Let \(n\) be the smallest integer such that \(n\cdot b\ge\operatorname{len}(C)\), let \(d=\operatorname{len}(C)-(n-1)\cdot b\), and let \(C_1, C_2, \ldots, C_{n-2}, C_{n-1}^{*}, C_n\) be the unique sequence of bit strings such that a) \(C=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\); b) \(C_n\) is a complete block; and c) if \(n>2\), then \(C_1,\ldots,C_{n-2}\), are complete blocks. Consequently, \(\operatorname{len}(C_{n-1}^{*})=d\), and \(1\le d\le b\), so that \(C_{n-1}^{*}\) is either a complete block or a nonempty partial block.

原本 PDF p.9

1. \(n\) を \(n\cdot b\ge\operatorname{len}(C)\) を満たす最小の整数とし、\(d=\operatorname{len}(C)-(n-1)\cdot b\) とする。また、次の条件を満たすビット列の一意な列 \(C_1, C_2, \ldots, C_{n-2}, C_{n-1}^{*}, C_n\) を定める。a) \(C=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\)。b) \(C_n\) は完全ブロックである。c) \(n>2\) の場合、\(C_1,\ldots,C_{n-2}\) は完全ブロックである。したがって、\(\operatorname{len}(C_{n-1}^{*})=d\) であり、\(1\le d\le b\) となるため、\(C_{n-1}^{*}\) は完全ブロックまたは空でない部分ブロックである。

2. Let \(Z^{*}=\mathrm{MSB}_d(\mathrm{CIPH}_K^{-1}(C_n))\), and \(Z^{**}=\mathrm{LSB}_{b-d}(\mathrm{CIPH}_K^{-1}(C_n))\).

原本 PDF p.9

2. \(Z^{*}=\mathrm{MSB}_d(\mathrm{CIPH}_K^{-1}(C_n))\)、\(Z^{**}=\mathrm{LSB}_{b-d}(\mathrm{CIPH}_K^{-1}(C_n))\) とする。

3. Let \(C_{n-1}=C_{n-1}^{*}\parallel Z^{**}\). Note that if \(C_{n-1}^{*}\) is a complete block, then \(Z^{**}\) is the empty string, and \(C_{n-1}=C_{n-1}^{*}\).

原本 PDF p.9

3. \(C_{n-1}=C_{n-1}^{*}\parallel Z^{**}\) とする。\(C_{n-1}^{*}\) が完全ブロックの場合、\(Z^{**}\) は空文字列であり、\(C_{n-1}=C_{n-1}^{*}\) となる。

4. Apply CBC decryption to \((C_1, C_2, \ldots, C_{n-1})\) with initialization vector \(\mathit{IV}\) and key \(K\) to produce \((P_1, P_2, \ldots P_{n-1})\).

原本 PDF p.9

4. \((C_1, C_2, \ldots, C_{n-1})\) に、初期化ベクトル \(\mathit{IV}\) と鍵 \(K\) を用いてCBC復号を適用し、\((P_1, P_2, \ldots P_{n-1})\) を生成する。

5. Let \(P_n^{*}=\mathrm{C}_{n-1}^{*}\oplus Z^{*}\).

原本 PDF p.10

5. \(P_n^{*}=\mathrm{C}_{n-1}^{*}\oplus Z^{*}\) とする。

6. Return \(P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\).

原本 PDF p.10

6. \(P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\) を返す。

When \(C_{n-1}^{*}\) is a complete block, CBC-CS1-Decrypt is equivalent to CBC decryption.

\(C_{n-1}^{*}\) が完全ブロックの場合、CBC-CS1-Decrypt はCBC復号と等価である。

3 Specification of CBC-CS2

3 CBC-CS2の仕様

Algorithm: CBC-CS2-Encrypt

原本 PDF p.10

アルゴリズム：CBC-CS2-Encrypt

Input: plaintext \(P\), such that \(\operatorname{len}(P)\) is valid;
initialization vector \(\mathit{IV}\);
key \(K\).

原本 PDF p.10

入力：平文 \(P\)（ただし \(\operatorname{len}(P)\) が有効な長さであるもの）；
初期化ベクトル \(\mathit{IV}\)；
鍵 \(K\)。

Output: ciphertext \(C\), such that \(\operatorname{len}(C)=\operatorname{len}(P)\).

原本 PDF p.10

出力：暗号文 \(C\)（ただし \(\operatorname{len}(C)=\operatorname{len}(P)\) を満たすもの）。

Steps:

原本 PDF p.10

手順：

1. Let \(n\) be the smallest integer such that \(n\cdot b\ge \operatorname{len}(P)\), let \(d=\operatorname{len}(P)-(n-1)\cdot b\), and let \(P_1, P_2, \ldots, P_{n-1}, P_n^{*}\) be the unique sequence of bit strings such that:
a) \(P=P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\); and
b) \(P_1, P_2, \ldots\) and \(P_{n-1}\) are complete blocks.
Consequently, \(\operatorname{len}(P_n^{*})=d\), and \(1\le d\le b\), so that \(P_n^{*}\) is either a complete block or a nonempty partial block.

原本 PDF p.11

1. \(n\) を \(n\cdot b\ge \operatorname{len}(P)\) を満たす最小の整数とし、\(d=\operatorname{len}(P)-(n-1)\cdot b\) とする。また、\(P_1, P_2, \ldots, P_{n-1}, P_n^{*}\) を、次を満たすビット列の一意な列とする。
a) \(P=P_1\parallel P_2\parallel\ldots\parallel P_{n-1}\parallel P_n^{*}\)。かつ
b) \(P_1, P_2, \ldots\) および \(P_{n-1}\) は完全ブロックである。
したがって、\(\operatorname{len}(P_n^{*})=d\) であり、\(1\le d\le b\) となるため、\(P_n^{*}\) は完全ブロックまたは空でない部分ブロックのいずれかである。

2. Apply CBC-CS1-Encrypt to the plaintext \(P\) with initialization vector \(\mathit{IV}\) and key \(K\) to produce \(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\).

原本 PDF p.11

2. 平文 \(P\) に、初期化ベクトル \(\mathit{IV}\) と鍵 \(K\) を用いてCBC-CS1-Encryptを適用し、\(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\) を生成する。

3. If \(d=b\), return \(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\); if \(d<b\), return \(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_n\parallel C_{n-1}^{*}\).

原本 PDF p.11

3. \(d=b\) の場合、\(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}^{*}\parallel C_n\) を返す。\(d<b\) の場合、\(C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_n\parallel C_{n-1}^{*}\) を返す。

When \(P_n^{*}\) is a complete block, then CBC-CS2-Encrypt, like CBC-CS1-Encrypt, is equivalent to CBC encryption. When \(P_n^{*}\) is a partial block, then CBC-CS2-Encrypt and CBC-CS1-Encrypt differ only in the ordering of \(C_{n-1}^{*}\) and \(C_n\).

原本 PDF p.11

\(P_n^{*}\) が完全ブロックの場合、CBC-CS2-Encrypt はCBC-CS1-Encryptと同様にCBC暗号化と等価である。\(P_n^{*}\) が部分ブロックの場合、CBC-CS2-EncryptとCBC-CS1-Encryptの違いは、\(C_{n-1}^{*}\) と \(C_n\) の順序だけである。

Algorithm: CBC-CS2-Decrypt

原本 PDF p.11

アルゴリズム：CBC-CS2-Decrypt

Input: ciphertext \(C\), such that \(\operatorname{len}(C)\) is valid;
initialization vector \(\mathit{IV}\);
key \(K\).

原本 PDF p.11

入力：暗号文 \(C\)（ただし \(\operatorname{len}(C)\) が有効な長さであるもの）；
初期化ベクトル \(\mathit{IV}\)；
鍵 \(K\)。

Output: plaintext \(P\), such that \(\operatorname{len}(P)=\operatorname{len}(C)\).

原本 PDF p.11

出力：平文 \(P\)（ただし \(\operatorname{len}(P)=\operatorname{len}(C)\) を満たすもの）。

Steps:

原本 PDF p.11

手順：

1. Let \(n\) be the smallest integer such that \(n\cdot b\ge \operatorname{len}(C)\), let \(d=\operatorname{len}(C)-(n-1)\cdot b\), and let \(C_1, C_2, \ldots, C_{n-2}, C_{n-1}, \mathrm{C}_n^{*}\) be the unique sequence of bit strings such that
a) \(C=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}\parallel C_n^{*}\);
b) \(C_{n-1}\) is a complete block; and
c) If \(n>2\), then \(C_1,\ldots,C_{n-2}\), are complete blocks.
Consequently, \(\operatorname{len}(C_n^{*})=d\), and \(1\le d\le b\), so that \(C_n^{*}\) is either a complete block or a nonempty partial block.

原本 PDF p.11

1. \(n\) を \(n\cdot b\ge \operatorname{len}(C)\) を満たす最小の整数とし、\(d=\operatorname{len}(C)-(n-1)\cdot b\) とする。また、\(C_1, C_2, \ldots, C_{n-2}, C_{n-1}, \mathrm{C}_n^{*}\) を、次を満たすビット列の一意な列とする。
a) \(C=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_{n-1}\parallel C_n^{*}\)。
b) \(C_{n-1}\) は完全ブロックである。かつ
c) \(n>2\) の場合、\(C_1,\ldots,C_{n-2}\) は完全ブロックである。
したがって、\(\operatorname{len}(C_n^{*})=d\) であり、\(1\le d\le b\) となるため、\(C_n^{*}\) は完全ブロックまたは空でない部分ブロックのいずれかである。

2. If \(d=b\), i.e., \(C_n^{*}\) is a complete block, then apply CBC-CS1-Decrypt to \(C\) with initialization vector \(\mathit{IV}\) and key \(K\), and return the result, \(P\). STOP.

原本 PDF p.11

2. \(d=b\)、すなわち \(C_n^{*}\) が完全ブロックである場合、\(C\) に初期化ベクトル \(\mathit{IV}\) と鍵 \(K\) を用いてCBC-CS1-Decryptを適用し、その結果 \(P\) を返す。STOP。

3. If \(d<b\), i.e., \(C_n^{*}\) is a partial block, then let \(\mathrm{C}'=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_n^{*}\parallel C_{n-1}\).

原本 PDF p.11

3. \(d<b\)、すなわち \(C_n^{*}\) が部分ブロックである場合、\(\mathrm{C}'=C_1\parallel C_2\parallel\ldots\parallel C_{n-2}\parallel C_n^{*}\parallel C_{n-1}\) とする。

4. Apply CBC-CS1-Decrypt to \(\mathrm{C}'\), and return the result, \(P\).

原本 PDF p.11

4. \(\mathrm{C}'\) にCBC-CS1-Decryptを適用し、その結果 \(P\) を返す。

Note that in Step 3, \(C_n^{*}\) precedes \(C_{n-1}\) in order to undo the corresponding swap within the ciphertext in Step 3 of CBC-CS2-Encrypt.

原本 PDF p.11

ステップ3で \(C_n^{*}\) を \(C_{n-1}\) より前に置くのは、CBC-CS2-Encryptのステップ3で行われた対応する暗号文の入れ替えを元に戻すためである。

4 CBC-CS3の仕様

Algorithm: CBC-CS3-Encrypt

原本 PDF p.12

アルゴリズム：CBC-CS3-Encrypt

Input: plaintext \(P\), such that \(\operatorname{len}(P)\) is valid; initialization vector \(\mathit{IV}\); key \(K\).

原本 PDF p.12

入力：平文 \(P\)（\(\operatorname{len}(P)\) が有効長であるもの）；初期化ベクトル \(\mathit{IV}\)；鍵 \(K\)。

Output: ciphertext \(C\), such that \(\operatorname{len}(C)=\operatorname{len}(P)\).

原本 PDF p.12

出力：暗号文 \(C\)（\(\operatorname{len}(C)=\operatorname{len}(P)\) を満たすもの）。

Steps:

原本 PDF p.12

手順：

1. Apply CBC-CS1-Encrypt to the plaintext \(P\) with initialization vector \(\mathit{IV}\) and key \(K\) to produce \(C_1 \parallel C_2 \parallel \ldots \parallel C_{n-2} \parallel C_{n-1}^{*} \parallel C_n\).

原本 PDF p.12

1. 平文 \(P\) に、初期化ベクトル \(\mathit{IV}\) と鍵 \(K\) を用いてCBC-CS1-Encryptを適用し、\(C_1 \parallel C_2 \parallel \ldots \parallel C_{n-2} \parallel C_{n-1}^{*} \parallel C_n\) を生成する。

2. Return \(C_1 \parallel C_2 \parallel \ldots \parallel C_{n-2} \parallel C_n \parallel C_{n-1}^{*}\).

原本 PDF p.12

2. \(C_1 \parallel C_2 \parallel \ldots \parallel C_{n-2} \parallel C_n \parallel C_{n-1}^{*}\) を返す。

Note that in Step 2, \(C_{n-1}^{*}\) and \(C_n\) are unconditionally swapped, i.e., even when \(C_{n-1}^{*}\) is a complete block; therefore, CBC-CS3 is not strictly an extension of CBC mode. In the other case, i.e., when \(C_{n-1}^{*}\) is a nonempty partial block, CBC-CS3-Encrypt is equivalent to CBC-CS2-Encrypt.

原本 PDF p.12

ステップ2では、\(C_{n-1}^{*}\) と \(C_n\) を無条件に入れ替える。すなわち、\(C_{n-1}^{*}\) が完全ブロックの場合も入れ替えるため、CBC-CS3はCBCモードの厳密な拡張ではない。一方、\(C_{n-1}^{*}\) が空でない部分ブロックの場合、CBC-CS3-EncryptはCBC-CS2-Encryptと等価である。
