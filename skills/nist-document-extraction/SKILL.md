# NIST資料の抽出・翻訳

原本、抽出状態、訳文のレビュー状態を区別する。修正済みの原文・訳文は`data/sp800-<slug>-trans.json`内の`html`・`html_ja`に保存し、数式用の別JSONを正本にしない。再抽出・再生成でも直接編集した数式と訳文を引き継ぐ。

## 本文数式

意味と構造を表す通常のLaTeXとして復元し、英日両方のHTMLに`\(...\)`または`\[...\]`で保存する。分数は`\frac`、平方根は`\sqrt`、添字・指数は`_`・`^`、総和・積分は`\sum`・`\int`とその上下限、行列・場合分け・複数行の式は`matrix`系・`cases`・`aligned`等で表す。KaTeXのCSS・JavaScript・フォントはローカルに配置する。

**PDFの文字座標を再現する数式は出力しない。** 座標は構造を読み取る手掛かりにだけ使う。`\mathrlap`・`\mathllap`・`\mathclap`、`\raisebox`、位置指定の`\kern`、`\rule`の罫線、絶対配置、文字ごとのHTML/CSSで式を組み立てない。`\htmlStyle`は禁止。`\vphantom`・`\phantom`等は原則使わず、括弧や高さの調整を座標再現の代替にしない。通常のLaTeX構造で表せないという理由だけで、本文数式を画像に置き換えない。

判読が曖昧なら、対象領域を原本PDFから300～600dpi相当で再レンダリングし、必要箇所を拡大する。小さなプレビューの引き伸ばしだけで済ませない。前後の定義、式の説明、同じ変数・式の別の出現箇所、計算例を照合し、記号、分母・分子の範囲、添字、指数、上下限、括弧の対応を決める。判断できなければ、公式PDFの別配布元、著者・機関の公開資料や実装を検索し、版を確認して補助証拠として使う。外部情報だけで原本の式を黙って書き換えない。

読めない値を推測で確定しない。暫定復元には`extraction_status: needs_review`を付け、迷った記号と使用した証拠を記録する。座標配置へのフォールバックを追加しない。数式を消したり、説明文を省略したりして修正済みと扱わない。

原文と訳文では同じ変数・数式・値を保持する。式が表示されるだけでは翻訳済みにしない。説明文の訳が未確認ならその状態を保ち、旧訳は履歴に残す。読み取り未確認の式を含むブロックはレビュー済みにしない。

図番号の付いた図と図内の数式は原本画像で保持できる。図の外の本文・キャプションの数式、数式を含む表はLaTeX・HTMLとして復元する。表の見出し・行・列の対応も保つ。

## 読み違えを防ぐ組み立て方

式全体の読み順を先に確定する。離れた位置に印字された`χ²=`や等号を分数の後ろへ移動しない。同じ高さの小さな文字でも、別の文節の変数を添字へ結合しない。例えば、配列`v_i`と「`v_1`を増やす」という説明は別々に復元する。`2^m`と後続の「m-bit」の`m`も区別する。

床関数・天井関数は括弧の上下の角を拡大して確認し、`\lfloor`・`\rfloor`等で表す。添字の末尾に本文のカンマを入れない。プライムは変数に付け、添字や前後の文から切り離さない。名前のある関数・統計量は`\operatorname{igamc}`、`\operatorname{expectedValue}`、`\mathrm{obs}`等を使って、一文字ずつの積に見えないようにする。

独立した分数・積分・総和の式には表示数式を使う。長い式は等号・加算など意味が保てる位置で`aligned`に改行し、分子、分母、指数、添字を読める大きさにする。幅に合わせて式全体を極端に縮小しない。数式を含む表にも固定の最小幅を強制せず、セル内の式は意味を保って改行する。最終ページの列幅で、表の右端の数値まで読めることを確認する。本文欄の実際の幅で英日両方を確認し、横スクロールに頼る前に意味を保った改行を検討する。

数式と本文の境界も確認する。文末のピリオドの後に別の変数定義が始まるときは、一続きの式にしない。脚注番号や序数の接尾辞はHTMLの`sup`、箇条書きは`ul`・`li`、ファイル名・コマンドは`code`で表す。脚注を名称や数値に連結しない。`G-SHA-1`の脚注4を`G-SHA-14`にしない。

長い16進シードやビット列は一つの値として保持し、原本の折り返しを新たな空白や別の値として保存しない。数学記号はKaTeXで表し、値のリテラルは改行可能な`code`等で保持できる。説明文を翻訳待ちにする処理でも、値を削除しない。英日両欄の文字数・全桁・先頭ゼロを照合する。

用語集・記号表も本文数式と同じ基準で照合する。`p^k`を`pk`にしたり、`H_0`の添字をセル内の別の位置へ残したりしない。表は見出しの階層、結合セル、列ごとの意味を維持する。複数の結果列を一つのセルへ詰め込まない。定義文を短縮して条件や値を落とさない。

## 確認

計算例は途中の等号、加算項、係数、最終結果まで一つずつ照合する。結果が一致していても、途中の式が正しいとは限らない。原本自体に計算・表記の不整合があれば、転記と数学的訂正を区別し、`math_review_notes`に原本の値・疑問点・確認根拠を記録する。訂正を採用する場合は、正誤表や確認した定義を示し、訂正箇所を読者へ明示する。

表の直下にある平均・分散、条件、変数定義、計算例も照合対象に含める。表の条件となる`K`・`M`、行名、Serial等の統計量、各P値を省略しない。ビットパターンの一覧では各パターンを独立した値として保存し、先頭ゼロ、桁数、行・列の対応、パターン数を確認する。

ページをまたぐ定義・式は次ページも確認する。置換対象の原文ブロックとページ参照が実際の式に対応することを確認し、同じ式の重複、数式の後ろに残った指数・添字・説明文の断片を除く。確認済みの式を編集したら照合記録を未確認へ戻し、修正後の表示を再確認する。確認記録には対象PDFの版・ページ・使用した解像度と、確認したHTMLを識別するハッシュを残す。

ローカルKaTeXを`trust: false`で使い、保存した式の構文と描画エラーを確認する。構文検証だけで正しさを判定せず、複雑な式は原本の高解像度画像とブラウザ表示を見比べる。既載の計算例があれば数値も確認する。再抽出で修正が失われないこと、本文に座標配置命令が再混入しないことを検証する。
