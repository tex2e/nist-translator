# SP 800-22 数式復元の確認記録

対象はローカルのSP 800-22 Rev.1a原本。配布先: https://nvlpubs.nist.gov/nistpubs/legacy/sp/nistspecialpublication800-22r1a.pdf

数式を含む333領域すべてに日本語訳を収録した。訳文は`draft`状態で、人手による翻訳レビューは未完了。本文中の数式は英日で保持し、数式内の説明語（`\text{}`）は日本語化している。

333領域を構造を表すLaTeXへ移行し、すべてについて原本画像と修正後のChrome表示を比較した。現在の原文HTMLに対応する照合記録は333領域で、最終照合の未記録は0。重複する1領域は正本の式と対応付け、本文では二重に表示しない。抽出・訳文のレビュー状態は別に保持する。原本への転記が確認できても、原本自体の数学的正しさや説明文の翻訳完了を意味しない。

確認記録は各ブロックの`math_reconstruction.source_check`に保存する。`browser_status`は数式表示の比較結果であり、説明文の翻訳完了や原本の数学的正しさを意味しない。`rendered_source_hash`で確認した原文HTMLを特定する。

曖昧な添字・計算例は原本PDFを432dpi相当でレンダリングして確認した。外部情報はNIST公式PDFと乱数生成プロジェクトの資料・実装一覧を確認した。版による値の違いを原本へ黙って適用しない。

図7領域と図中の数式は画像を維持。本文数式はhtmlとhtml_jaに保存し、別の数式JSONは作成しない。KaTeXはローカル配布版を使用。

## 原本の不整合・要確認箇所

- PDF p.28 / `pdf-p0028-math-050`: 原本p.28は |π−1/2|<τ の例について「the test is not run」と述べた直後、「the runs test is applicable」と述べる。両者が矛盾するため、式と前提条件を保持し、後者に沿った説明であることを記録する。
- PDF p.33 / `pdf-p0033-math-076`: 原本p.33の最後の計算例は指数を正の0.596953/2と印字している。直前の式の負号および結果0.741948と不整合。432dpiで負号がないことを確認し、原本どおり転記した。
- PDF p.45 / `pdf-p0045-math-137`: 原本p.45は同じ計算例のσを0.002703と3.125の両方で記す。分散値の誤記の可能性があるが原本の値を保持。
- PDF p.47 / `pdf-p0047-math-145`: 原本p.47はπ₄=0.25と記す。列挙された確率の和が1にならないが、原本の値を保持。
- PDF p.48 / `pdf-p0048-math-147`: 原本p.48はνの添字を大文字Iと印字する。前後のν_iと表記が異なるが原本の大文字を保持。
- PDF p.49 / `pdf-p0049-math-156`: 原本p.49はv111=0と記すが、直後のψ₃²の計算例はv111²=1を使う。原本の値を保持して不整合を記録。
- PDF p.50 / `pdf-p0050-math-158`: 原本p.50の一般式はigamcの第2引数を2で割らないが、直後の数値例では2で割る。432dpiで確認し、原本の一般式を保持。
- PDF p.52 / `pdf-p0052-math-171`: 原本p.52のφ⁽⁴⁾ではlog0.01等と結果-1.83437197が整合しない。原本を転記したまま要確認。
- PDF p.52 / `pdf-p0052-math-172`: 原本p.52のχ²の等式とP値の数値に不整合がある。χ²=0.502193は原本の表記を保持し、数学的修正は未確定。
- PDF p.63 / `pdf-p0063-math-220`: 原本p.63はerfcの引数の分母を√nと記す。p.25の√2と不整合だが、原本の転記として保持。
- PDF p.64 / `pdf-p0064-math-223`: 原本p.64の第2の積分はduの直後に余分な9を印字する。変数変換およびigamcとの等式と不整合。432dpiで確認し、原本の9を保持。
- PDF p.68 / `pdf-p0068-math-241`: 原本p.68の第3項は分子に0.1336N、分母に0.13336Nと印字する。432dpiで両方を確認し、原本の値を保持。
- PDF p.69 / `pdf-p0069-math-243`: 原本p.69の最初の指数ではπに添字iを付けるが、後続の定義では虚数単位iを掛ける。432dpiで確認し、原本の添字を保持。
- PDF p.79 / `pdf-p0079-math-268`: 原本p.79の第6階級は−1.5<T≤2.5と印字され、前の階級と重複する。またπ₄=0.25と記す。432dpiで確認し、原本の値を保持。
- PDF p.81 / `pdf-p0081-math-273`: 原本p.81は総和の下限をi+1と印字する。i=1と解釈できるが原本の表記を保持して要確認。

## 検証範囲

ローカルKaTeXの構文検証、座標命令の混入検出、英日への数式保存、図の保持、再抽出で編集が残ることを自動検証する。Chromeで原本との比較に加え、対訳ページの実際の列幅で複数行のχ二乗式・積分・総和、結果表、行列と128桁のシード値を確認した。長い値は英日両欄で全桁を保持する。構文や表示の正常さと、原本への忠実さ・数値の正しさは別の確認項目である。

翻訳確認では、数式を含む表32ブロックの行数・列数とラベルを照合した。例1・例2・例4・例5の検定結果表で、初回訳に見出し・検定名のずれと先頭検定名の欠落があったため、原文のセル配置と数値を保って修正した。例3も含め、5例の検定名を統一した。数式を含む333領域の訳文は引き続き`draft`であり、人手による全訳文レビューは完了していない。

関連する自動検証23件（数式14件・自動翻訳9件）を実行して成功した。対訳欄の表に指定されていた最小幅640pxを外し、部分和の長い式を加算位置で改行した。結果表の日本語側ではP値列の折り返しを止めた。1280px幅のChromeで、数式ブロックの英日両欄に横方向のはみ出しがないことを確認した。
